# Kalima Daily (macOS)
SwiftUI Mac app to build a daily habit of reciting the 4th Kalima (Kalima Tamjeed):
read once or three times, or listen as the worst-case minimum.

Features: streak, daily rewards, share, easy copy, time spent in app, reminders
(daily, and if missed: 2 days, weekly, monthly, quarterly, 6-month, yearly),
benefits with hadith grading, how to use, AI prompts, GitHub section.

Build + install: `./install.sh`
